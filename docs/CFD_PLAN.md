# 計算でどこまで迫れるか:プロペラの CFD と学習サロゲートの方策(2026-10-30)

> **2026-10-31 の方針転換**:主目的を「PhysicsNeMo(特に PINN)の評価」に変えました。ラピッドプロトタイピングを想定し、計画の中心は `docs/PHYSICSNEMO_PLAN.md` に移ります。
> この文書の段階 0〜3 の結果は、評価の正解データとして使います。段階 3 の壁まで解像する LES はやめました。段階 4〜6 は PhysicsNeMo の計画に置き換えます(段階 5 のアンサンブルは課題 B の学習データとして残します)。

装置を動かせない日に、理究(GB200 NVL4、約 200 ノードが空き)で何をどの順で計算するかの計画です。
目的は「CFD を回すこと」ではなく、**いまのツインで決まっていないこと・合っていないことを、計算で決着させる**ことです。

## 1. 何を決着させたいか(仮説の一覧)

いまのツイン(BEMT + モーター、`twin/README.md`)で残っている問題を、計算で答えが出る問いに直します。

| # | 問い | いまの扱い | 計算で何が分かるか |
|---|---|---|---|
| H1 | 推力が回転数の **2.23 乗**になるのはなぜか | 揚力の効きを (Re/Re₀)^0.49 とした経験式 | 低 Re の翼の性質か、コップとの干渉か、羽根の 3 次元効果かを切り分ける |
| H2 | 形状抵抗が平板の **7.1 倍**(kD)は本当か | kD・b・R が打ち消し合って決まらない | **空力トルクを CFD で単独に出す** → kD を外から固定 → R と b が決まる |
| H3 | 逆転のほうが空力負荷が軽い(kD_r 5.0)のはなぜか | 係数を分けて合わせただけ | 逆転の後流がコップに当たる流れ場を直接見る |
| H4 | 逆転で天秤が −0.14 g になる仕組み(η = 0.93) | 「後流の 93 % が皿に戻る」という仮定 | 天秤に載っている物すべてに働く力を合計して、天秤の読みそのものを予測する |
| H5 | 部分 duty(40 %)でツインの回転数が 9 % 遅い | 未解決 | 低速(Re ≈ 3〜6 千)の抵抗が BEMT の式より小さいか |
| H6 | コップとの距離が 11.8 mm(スキャン)なのに 14 mm で計算していた | 地面効果の簡易式 | 距離を振った計算で感度を見る |

検証に使える実測は次のとおりです。いずれも装置なしで使えます。

- 推力 5 点と、そのときの回転数(IMG_5785 と `TEL` を同時に記録、`twin/data/thrust_steps_IMG_5785.json`)。
  **回転数は実測値を CFD に与える**ので、モーターモデルを通さずに空力だけを比べられます。
- 逆転時の天秤の読み −0.14 g(IMG_5779)。
- 正転・逆転とプロペラなしの回転数(モーターモデルを通して空力トルクと比べる)。
- 形状:プロペラのスキャン(IMG_5778、ピッチ 18°・ねじれなし、弦長の表)、天秤に載せた装置のスキャン(IMG_5782、ミリ単位)。

## 2. 流れの条件(見積もり)

| 回転数 rpm | 翼端速度 | Re(0.75R、弦長 29.5 mm) | 1 回転 |
|---|---|---|---|
| 3067(全速) | 10.3 m/s | 1.5 万 | 19.6 ms |
| 2184 | 7.3 m/s | 1.1 万 | 27.5 ms |
| 1592 | 5.3 m/s | 7.8 千 | 37.7 ms |
| 1190 | 4.0 m/s | 5.8 千 | 50.4 ms |
| 695 | 2.3 m/s | 3.4 千 | 86.3 ms |

- マッハ数は 0.03 で、非圧縮で扱えます。
- Re が 3 千〜1.5 万なので、乱流モデルより**壁まで解像する LES(ほぼ DNS)**のほうが素直です。境界層の厚さは 0.2 mm 程度、壁の格子は 30〜50 µm と見積もりました。
- 弦長が半径とほぼ同じ幅広の 3 枚羽根(ソリディティ約 0.8)で、羽根どうしの干渉が強いと考えられます。BEMT が苦手な領域です。
- 羽根のたわみを見積もると、推力 5.5 mN/枚・厚さ約 0.9 mm で先端の変位は数 µm です。**空力弾性は無視**します。
- 羽根の厚さは未測定です。質量 2.0 g と羽根の面積(1 枚 5.1 cm²)から 0.8〜1.2 mm と推定しました。前縁の形と合わせて**不確かさとして振ります**。

## 4. 計算の段階

速くて安い計算で外れを潰してから、重い計算に進みます。各段階に「次へ進む条件」を置きます。

### 段階 0:形状を作り、確かめる(手元、約 2 時間)

1. **プロペラの CAD をパラメータから作る**:弦長の表、ピッチ 18°、厚さ t、前縁・後縁の丸み、ハブ(0.345R)を入れます。
   出力は閉じた STL です。スキャンの点群はそのままでは穴と二重面があり、メッシュに使えません。
2. **装置の形状**:IMG_5782 のミリ単位のメッシュから、紙コップ(円錐台)、モーター、天秤の皿、天秤の本体、机を単純な形で作り直します。
   どの部品が皿に載っているか(天秤の読みに入る力)を区別しておきます。
3. **スキャンとの照合**:作った形状とスキャンの距離の分布(Hausdorff)を見ます。
   プロペラ直径 64.0 mm、コップ上面から 11.8 mm などの寸法が合っていれば次へ進みます。
4. パラメータ(t、前縁半径、ピッチ ±2°、スパン方向の反り、コップまでの距離、軸の傾き)を変えた形状を自動で作れるようにします。

### 段階 1:翼断面の空力特性(理究の CPU、1 ケース 1 ノード、並列 100〜200 ケース)

- スパン方向を周期にした薄い領域で、翼断面の LES(pimpleFoam)を回します。
- 振る条件:迎角 −8〜25°(1〜2° 刻み)、Re 3 千・6 千・1 万・1.5 万・2 万、厚さ 2 通り、前縁 2 通り。
- **BEMT の平板の式(cl = kL·(Re/Re₀)^m·2πα など)を、計算で出した表に置き換えます**。kL・kL_m・kD を合わせ込みではなく計算で決めることになり、H1・H5 に直接効きます。
- 計算の確かさは、低 Re の平板翼の公開実験(Re 1 万前後の平板、ここは文献を確認します)と比べて確かめます。
- 進む条件:公開実験と傾向が合うこと。表を入れた BEMT の推力が、実測 5 点に ±15 % 以内で合うこと。

### 段階 2:回るプロペラの 3 次元計算・スクリーニング(MRF の定常 RANS + 遷移モデル、1 ケース 1 ノードで数時間)

- 回転座標系(MRF)で、プロペラとコップ、モーター、皿を含めて計算します。
- 回転数は実測の 5 点、それぞれ正転と逆転で 10 ケースです。格子は 3 段階(約 5M、15M、40M セル)にします。
- 実測の推力と逆転の天秤の読みに、どこまで合うかを先に見ます。
- 羽根に沿った力の分布を BEMT と並べて、ハブ側・翼端・コップの上のどこで BEMT が外れるかを特定します。
- 進む条件:全速の推力が ±15 % 以内。外れたら段階 0 の形状(ピッチの符号、反り、厚さ)を疑います。

### 段階 3:本番の計算(回転格子を動かす壁解像 LES、全速の正転・逆転)

- AMI でプロペラの周りの円筒を実際に回し、装置全体と部屋を含めて計算します。
- 規模は 2,000 万〜1.5 億セル、時間刻み約 5 µs で約 30 回転(後流が抜けるまで 10 回転、平均に 20 回転)です。
- **10〜40 ノードで一晩**と見積もりました。格子 3 段階で、推力の変化が 3 % 以内になるまで細かくします。
- 出力:推力、空力トルク、天秤に載っている物すべてに働く力(天秤の読み)、後流の速度場、羽根の表面圧。
- 答える問い:H2(空力トルク → kD)、H3・H4(逆転の流れと天秤)、H6(コップとの距離)。

### 段階 4:別の方法での照合(GPU)

ナビエ・ストークスを有限体積法で解く OpenFOAM とは数値の作りが違う方法で、同じケースを解きます。合えば計算の誤差ではないと言えます。

- 候補は GPU の格子ボルツマン法(XLB:NVIDIA Warp を使う Apache-2.0 のパッケージ)と、渦法の中程度の精度の計算です。
- 回る形状を扱えるかは要確認です。だめなら、段階 3 の格子違いと時間刻み違いで代えます。

### 段階 5:不確かさと同定(手元 + 理究)

1. 形状の不確かさ(厚さ、前縁、ピッチ ±2°、反り、コップとの距離、軸の傾き)と回転数を振った**アンサンブル**を作ります。段階 2 の MRF で 100〜300 ケースです。
2. 推力・空力トルク・天秤の読みを、ガウス過程の**エミュレータ**で表します。
3. 実測(推力 5 点、逆転の天秤、正転・逆転・プロペラなしの回転数)と、モーターのパラメータ(K、R、b、V0、c_flag)を**同時にベイズ推定**します。
   空力トルクを CFD 側から与えるので、kD・b・R が打ち消し合う問題が解けるはずです。
4. 結果として、**R と b の予測値を出します**。次に装置を動かす日にテスターで R を測れば当否が分かる、反証できる予測です(ADC 校正の課題と合流します)。

### 段階 6:学習サロゲートとツインへの組み込み(GPU)

用途を 2 つに分けます。

- **推力・トルクなどの数値**:ケースが数百なら、表とガウス過程のほうが学習モデルより確実です。BEMT の表(`params.json` の aero)を CFD 補正済みのものに置き換え、ページの JS もそのまま使えます。
- **流れ場**(3D ツインで後流を見せる、ピッチやコップの高さを変えて形を探す):ここで **PhysicsNeMo** を使います。
  - データ:段階 2・3・5 の時間平均(回転座標で位相平均)した流れ場、数百ケース。
  - モデル:MeshGraphNet と Transolver(GeoTransolver)を比べます。DoMINO の学習済みモデル(自動車)からの追加学習も試します。
  - **比較の基準**:POD(固有直交分解)+ ガウス過程。これに勝てなければ採用しません。評価は学習に入れていないケース(たとえば学習にないコップの高さ・ピッチ)で行い、合格の目安は推力の誤差 5 % 以内、後流の速度の誤差 10 % 以内です。
  - ブラウザでは、学習したモデルの出力を POD のモード係数にして小さな MLP に蒸留し、重みを JSON にして `twin3d.html` で描きます。
- **CFD との計算量・精度の比較**は、すべての段階で行います。比べ方は `docs/PHYSICSNEMO_PLAN.md` にまとめました。

### 並行して進めるもの(装置不要)

- **温度モデル**:撮影ごとに全速の回転数が 51.3 → 48.6 Hz と下がる現象を、既存のホストのログと時刻から、銅損 → 巻線温度 → R(T) の 1 次遅れで当てはめます。手元で計算できます。
- **次の実験日の計画**:計算の結果から、仮説をいちばん強く区別できる測り方を選びます(スペーサーでコップとの距離を変える、逆転の後流が皿に戻らない置き方など)。

## 6. 危険と対策

- **spack の OpenFOAM が aarch64 で一通り動くか**:最初に小さな例題(回転する AMI)で確かめます。だめならコンテナで OpenFOAM を使います。
- **低 Re の境界層の遷移は計算でも難しい**:RANS は段階 2 のふるい分けに留め、結論は段階 3 の LES と段階 4 の照合で出します。
- **部屋の空気の循環**:実験の部屋の形は分かりません。計算領域の大きさを変えて、推力への影響を見積もります。
- **形状の不確かさ**が計算誤差より大きい可能性があります。段階 5 で振って、「計算が外れた」と「形が違う」を分けます。
- **学習サロゲートが基準より良くならない**可能性があります。その場合は表とガウス過程で組み込み、学習の結果は記録として残します。
