# twin/ — v36 リグのデジタルツイン

ESPr Developer(v36 ファーム)→ L293D ×2並列 → 130級DCモーター → 約 67 mm 3枚羽根プロペラ、を1本の時間積分で再現します。パラメータは iPhone 動画2本から同定しました。

| 動画 | 指令 | 主に決まるもの |
|---|---|---|
| `IMG_5741.mov`(30 fps) | `dcm:speed 255` 2秒 → `dcm:off` | 定常回転数、惰性停止(摩擦・空力) |
| `IMG_5742.MOV`(60 fps、同期 LED) | `dcm:speed 255` 3秒 → `dcm:speed 51`(20 %)8秒 → `dcm:off` | 20 % での減速曲線 → 巻線インダクタンス L |

| ファイル | 内容 |
|---|---|
| `motor_twin.py` | ツイン本体(ファーム + 電気 + 機械)。CLI でコマンド列をシミュレート |
| `identify.py` | 動画 → ω(t) 抽出(音声のブラシ雑音 + 映像の羽根追跡)→ 惰性停止からの一次同定 |
| `fit_lowduty.py` | 2本の動画をまとめて再同定(L, Tc/J, c/J, R, Ts)。K 固定の旧手順 |
| `fit_joint.py` | **現行**。プロペラあり/なしの全観測で K, R, L, 回転子 J, Tc, c(`--bemt` では kD), V_bk を同時同定 |
| `bemt.py` | プロペラの翼素運動量理論(静止推力)。実測形状から推力・トルク・後流を回転数の表にして `params.json` の `aero` へ |
| `compare_runs.py` | 2本の実測とツインの比較図 → `data/compare_runs.png` |

| `twin.html` | 可視化(ブラウザで開く)。同じモデルの JS 版、v36 と同じコマンドで操作、実測点を重ね描き |
| `twin3d.html` | 3D ビュー。実機スキャン + パラメトリックなモーター/プロペラを同じツインで回す。質量から J を計算 |
| `scan_to_web.py`, `3d/` | Object Capture のスキャン(OBJ)を水平化・スケール合わせして web 用に書き出す |
| `data/*_measured.json` | 動画から取り出した実測値 |
| `data/sustain20_hostlog.json` | IMG_5742 撮影時のコマンド送信時刻(Mac 側) |

## モデル

```
電気 drive : 1 kHz PWM を1周期ごとに厳密に解く(周期内は ω 一定)
             on  (d·T)  : L di/dt = (Vs − V0) − (R + rd) i − K ω
             off (EN=LOW): 出力 Hi-Z。巻線電流はクランプダイオード経由で VCC2 へ高速減衰し、0 で止まる
                           L di/dt = −(Vs + 2Vf) − R i − K ω
電気 coast : i = 0                                          (EN=LOW → 出力 Hi-Z)
電気 brake : |K ω| > V_bk のときだけ L di/dt = −(K ω − V_bk) − R i  (両入力 HIGH。ハイサイドは吐き出し専用なので、
             片側ハイサイド + 反対側の上側クランプダイオード経由で V_bk ≈ 2.2 V 失う → ブレーキは弱い)
機械       : J dω/dt = K⟨i⟩ − Tc sgn ω − b ω − c ω|ω|        (⟨i⟩ = 周期平均電流)
             ω = 0 で |K⟨i⟩| ≤ Ts なら停止保持(静止摩擦 + コギング)
ファーム   : 5 ms ループ、整数 duty、ramp / ramp-step 排他、brake・off 後は duty=0
```

**L/R ≈ 0.35 ms** に対して 20 % の on 時間は 0.2 ms しかないため、低 duty では電流がほとんど立ち上がりません(20 % で起動時 ⟨i⟩ ≈ 0.04 A、duty 平均電圧モデルなら ≈ 0.13 A)。最初のモデル(PWM 平均)はここを見落としていて、「20 % で回り続ける」と誤って予測しました。

## 動画からの同定

1本の .mov から独立な2系統のセンサーを取り出します。

- **音声**:通電中はブラシが倍音コム(k·f_rot、2–14 kHz)を出す。調波和探索で f_rot を求めると、全速で **51.28 Hz(IMG_5741)/ 50.3 Hz(IMG_5742)**。coast や 20 % では電流が小さくコムが消える(20 % では代わりに 1 kHz PWM 音の 1000/k Hz 線が出る)。
- **映像**:黄色い羽根を HSV で抽出し、回転中のブラー円盤に楕円をフィットして透視を補正。極座標プロファイルをフレーム間で相互相関して羽根の角度ステップを取る。3枚羽根なので見かけのステップは 120° で折り返す。60 fps の IMG_5742 では、停止から逆向きにたどって連続化(−31 → 0 → +52 → −51 → 0 を一続きの減速として解く)。
- **同期 LED**(IO14、`dcm:*` の ACK ごとに 100 ms 点灯):IMG_5742 では 3回の点灯がちょうど 6 フレームずつ写り、Mac 側の送信時刻との差は 5.819 s ± 5 ms。

| 観測量 | 値 |
|---|---|
| IMG_5741 通電開始 / coast 開始 / 停止 | 2.817 / 4.817 / 5.583 s |
| IMG_5741 停止直前の角速度 | 22.5 → 2.1 rad/s(30 fps、4 点) |
| IMG_5742 全速 / 20 % / off(LED) | 7.870 / 10.888 / 18.842 s |
| IMG_5742 20 % での減速 | 50.8 Hz → 停止 11.864 s(0.976 s)。11.13–11.85 s に 44 点の ω |

### 同定結果(`fit_lowduty.py`)

| パラメータ | 値 | 決め手 |
|---|---|---|
| L | 1.9 mH(L/R ≈ 0.35 ms) | IMG_5742 の 20 % 減速曲線(RMS 誤差 5 rad/s、停止時刻 0.974 s vs 実測 0.976 s) |
| Tc | 0.26 mN·m | 2本の低速域の減速 × J |
| c | 6.9e-9 N·m·s² | IMG_5741 の全停止時間 × J |
| R | 5.4 Ω(全速電流 ≈ 0.49 A) | 全速の定常回転数 |
| Ts | 0.32 mN·m(≈ 1.2 Tc) | 冷間始動しきい値 47 %(README)を PWM 分解モデルで評価 |

動画だけでは**比**しか決まりません(電流も絶対トルクも測れないため)。J は質量の実測で決まりました。K は事前値のままで、K を固定したまま J を実測値にすると R ≈ 7.5 Ω と 130 級としては大きく出ます。IMG_5744 のブレーキ効果の弱さと合わせ、K は事前値より小さい(≈ 1e-3)可能性が高く、1円玉あり動画 IMG_5745 の惰性/ブレーキ比較で決める予定です。

| 事前値 | 値 | 根拠 |
|---|---|---|
| J | **7.4e-7 kg·m²(実測ベース、±12 %)** | プロペラ 2.0 g(電子天秤 0.1 g)× 平置き写真の輪郭(羽根 ⟨r²⟩ = 0.462 R²、ハブ/R = 0.345)、D = 61–67 mm、回転子 6e-8 を加算。当初の 1.0e-6 は 88 mm を仮定した過大評価 |
| K | 2.0e-3 N·m/A | 130級モーター(3 V 無負荷 ≈ 14000 rpm) |
| Vs, V0, rd, Vf | 4.9 V, 1.3 V, 0.6 Ω, 1.0 V | USB 5V、L293D データシート(並列で傾き半分) |

### 検算と予測

- 冷間始動:45 % 不転 / 50 % 起動(README の実測どおり)。
- **回転中に下げた場合の維持限界 ≈ 40 %**:100 % → 40 % は ≈ 270 rpm で辛うじて維持、30 % 以下は停止。次に実機で確かめる価値のある予測です。
- IMG_5741 の惰性停止は 0.05 s 以内で一致(図 `data/compare_runs.png`)。
- 全速の回転数は撮影ごとに 2 % ほど違う(51.28 / 50.3 Hz)。ツインは前者に合わせています。

## 使い方

```bash
python3 twin/motor_twin.py                                     # IMG_5741 を再現
python3 twin/motor_twin.py -s "0:dcm:speed 255" -s "1.5:dcm:speed 102" -s "6:dcm:off" -T 7
python3 twin/compare_runs.py                                   # 2本の比較図(matplotlib)
python3 twin/identify.py IMG_5741.mov --write                  # 一次同定(numpy scipy opencv-python-headless)
python3 twin/fit_lowduty.py --write                            # 2本で再同定(identify.py の後に実行)
```

`identify.py --write` は PWM 平均の簡易式で R/Tc/c/Ts を上書きするので、続けて `fit_lowduty.py --write` を実行してください。

`twin.html` は Chrome でローカルに開くと「実機に接続(Web Serial)」が出て、送ったコマンドをツインと実機の両方に流せます(未検証)。

## 精度を上げる次の撮影

1. **維持限界の確認**:100 % → 50 / 40 / 30 % を各5秒。ツインは 40 % がほぼ境界と予測。
2. **duty スイープ**:100→50 % を 10 % 刻み・各2秒。各 duty の定常回転数(音声コム)が K・R・L を同時に拘束し、事前値 K が不要になる。
3. 電流を測る(USB 電流計、または シャント抵抗 → ESPr の TOUT)と、J と K の絶対値が決まる。

## プロペラなし実験と同時同定(`fit_joint.py`、現行パラメータ)

1円玉は振動がひどかったため、代わりにプロペラを外し、軸にテープの旗を付けて撮影しました(`IMG_5759.MOV`、60 fps、真上から、同期 LED 10/10 一致、動画 = ホスト + 6.671 s)。

| 観測 | 値 | 取り方 |
|---|---|---|
| 無負荷 100 % 定常 | **61.4 Hz**(3680 rpm) | 音声コム。半分の 30.7 Hz は z 2.0 で否定 |
| 無負荷 80 % 定常 | 44.6 Hz | 同上(60 % 以下は 1 kHz PWM 線に埋もれる) |
| 無負荷 惰性停止 / ブレーキ停止 | 0.278 / 0.244 s | 旗領域のフレーム差分 |
| プロペラあり 100 % 定常 | 50.8 Hz(撮影ごとに 51.3→48.6、温まると下がる) | 音声コム。半分の 25 Hz は z 4.0 で否定 |

無負荷では負荷が摩擦だけなので回転数 ≈ V'/K、プロペラありの負荷トルクは実測 J × 惰性減速から既知 → K が決まります。全観測 8 本(上の 4 + 惰性/ブレーキ/20 % 減速)に最小二乗:

| パラメータ | 値 | 1σ |
|---|---|---|
| K | **8.5e-3 N·m/A**(旧事前値 2e-3 の 4.3 倍) | 9 % |
| R | 10 Ω | 56 % |
| L | 11 mH(L/R ≈ 1.1 ms) | 49 % |
| 回転子 J | 1.9e-7 kg·m²(合計 J = 8.8e-7) | 41 % |
| Tc | 0.25 mN·m | 32 % |
| V_bk | 2.2 V | 27 % |

全観測が ±1σ 前後で合い、20 % の停止時刻だけ −2σ(0.933 vs 0.976 s)。R と L は強く相関していて個別には決まりにくい。電流はプロペラあり全速 0.08 A、無負荷 0.03 A と小さく、低回転・高抵抗の巻線のモーターです。

## ESPr の ADC で K を直接測る(`adc_backemf.py`、現行パラメータ)

配線は WIRING.md「逆起電力プローブ」(端子A → 10k → TOUT → 2k → GND、端子B → 270 Ω → GND)。ファームの `adc:cap 200 4000 500 dcm:off` で、全速から惰性に入る前後を 5 kHz で記録します(`tools/adc_capture.py`、データは `data/adc/`)。

- 惰性中の端子A = 逆起電力 K·ω。整流子は 3 セグメントなので電圧に **1 回転 3 周期のリップル**が乗り、その基本周波数 / 3 が回転数(駆動中 187.8 Hz → 62.6 Hz。iPhone 音声の 61.4 Hz と 2 % で一致)。
- 同じ窓の平均電圧と回転数を直線に当てると **K = 6.06e-3 V·s/rad**(切片 +0.001 V、残差 0.5 %、130–359 rad/s)。誤差は ADC の利得(未校正、数 %)が支配的。
- `fit_joint.py` の K = 8.5e-3 は 30 % 大きかった。原因は L293D の降下 V0 を 1.3 V と仮定していたこと。駆動中の端子A = 4.29 V(ハイサイド降下 ≈ 0.6 V)、モーター両端 ≈ K·ω + R·i ≈ 2.7 V からローサイド ≈ 1.6 V、合計 ≈ 2.2 V。
- K を測定値に固定して `fit_joint.py --fix-K 6.06e-3 --free-V0` で再同定 → **V0 = 2.35 V**(上の推定と独立に一致)、**R = 4.9 Ω**、L = 5.7 mH、回転子 J = 1.65e-7、Tc = 0.24 mN·m。V_bk は上限 4.5 V に張り付き(このモーターの逆起電力ではブレーキはほぼ効かない、≳ 3 V とだけ言える)。

## 推力の実測(`data/thrust_IMG_5769.json`)

プロペラを付けた装置ごと電子天秤(TANITA KJ-212、微量モード 0.1 g)に載せ、duty を 100 → 80 → 60 → 50 → 40 % と 5 秒ずつ下げて表示を撮影しました(`IMG_5769.MOV`)。表示が**増える**ので風は上向き(反作用で装置が押し下げられる)。停止中は前後とも 34.1 g でゼロに戻ります。動画とコマンドの対応は、表示の段差と 100 % の音声コムの立ち上がりから決めました(動画 = ホスト + 16.9 s。今回は LED が画面内で小さく使えなかった)。

| duty | 表示 | 推力 | 回転数 | ツイン(回転数 / 推力) |
|---|---|---|---|---|
| 100 % | 36.0 g | **1.9 gf** | 3164 rpm(音声コム・ADC リップルとも 52.7 Hz) | 3034 rpm / 1.75 gf |
| 80 % | 34.94 g | 0.84 gf | ≈ 2100 rpm(推力 ∝ n² から) | 1850 / 0.65 |
| 60 % | 34.58 g | 0.48 gf | ≈ 1590 | 1281 / 0.31 |
| 50 % | 34.3 g | 0.2 gf | ≈ 1025(±25 %) | 836 / 0.13 |
| 40 % | 34.2 g | 0.1 gf | ≈ 720(±50 %) | 88 / 0.00 |

- **C_T ≈ 0.34**(D = 61–67 mm で 0.28–0.41)、C_Q ≈ 0.14(ツインの c から)、静止推力効率 FM ≈ 0.16、後流 ≈ 3.1 m/s(運動量理論)。ツインには T = kT·ω²、**kT = 1.70e-7 N·s²** として追加(`params.json`、両ページの推力レーン、2D 版の「推力測定」プリセットは実測点を重ね描き)。
- **部分 duty でツインの回転数が 12–20 % 低い**(推力 ∝ n² を仮定した場合)。20 % 減速の停止時刻が −2σ だったのと同じ傾向で、L293D の降下 V0 を電流によらず 2.35 V と置いているのが原因と考えられる(実際のダーリントン出力は低電流ほど降下が小さい)。80 % 以下は PWM 雑音で音声コムも ADC リップルも回転数が読めないため、次は PWM のオフ期間だけ ADC で読む方法で直接確かめる。

## 部分 duty の回転数と粘性摩擦(現行パラメータ)

80 % 以下は PWM 雑音で音声コムも ADC リップルも回転数が読めなかったため、ファームに回転計コマンド **`adc:emf`** を追加しました。EN を 1.5 ms 切って巻線電流を消し、開放端子の電圧(= 逆起電力)を読んで PWM を戻します(速度低下 < 0.5 %)。20 kHz の `adc:cap 50 2000 0` で、オフ期間に逆起電力のプラトーが見えることを先に確認しています(`data/adc/partial_duty_50us.json`)。

| duty | 回転数(adc:emf、10 回平均) | 推力から(∝ n²) | 旧ツイン | 新ツイン |
|---|---|---|---|---|
| 100 % | 3070 ± 72 rpm | 3164 | 3034 | 3057 |
| 80 % | 2216 ± 80 | 2104 | 1850 | 2169 |
| 60 % | 1628 ± 67 | 1590 | 1281 | 1629 |
| 50 % | 1269 ± 28 | 1027(±25 %) | 839 | 1227 |
| 40 % | 712 ± 19 | 726 | 147 | 700 |
| 30 % | 0(停止) | — | 0 | 0 |

推力 ∝ n² は 50 % 以外(推力 0.2 gf で天秤の分解能が足りない)で確認できました。L293D の降下を電流依存にしても(rd 自由)全観測は同時に合わず、**粘性摩擦 b·ω** を加えると 13 観測すべてが ±1.5σ に入りました(コスト 32 → 4.8、20 % 減速の停止時刻も −2.3σ → +0.6σ)。

`fit_joint.py --fix-K 6.06e-3 --free-V0 --free-b`:R = 7.7 Ω、L = 2.7 mH(L/R = 0.36 ms)、V0 = 2.17 V、回転子 J = 2.65e-7(合計 9.5e-7)、Tc = 0.28 mN·m、**b = 3.6e-7 N·m·s**(全速で 0.12 mN·m)、c = 2.85e-9、V_bk = 1.16 V。冷間始動 45 % 不転 / 50 % 起動、30 % 停止も再現します。

## 回転数の閉ループ制御とライブ同期(`rpm:set`、`tel:on`)

- **回転計**:50 ms ごとに EN を約 2 ms 切って逆起電力を読む(`adc:emf` と同じ)。駆動の中断は 4 %。1 回の読みは整流子リップルで ±20 %(標準偏差 12 %)ばらつくので、指数移動平均(α = 0.5)をかける。
- **制御則**:duty = フィードフォワード(ツインの定常 duty–回転数表)+ Kp·e + I、**Kp = 0.04 duty/rpm、Ki = 0.25 duty/(rpm·s)**。停止中は 100 % でキック(フィルタ値が目標の 40 % を超えるまで、最大 0.3 s)。**duty の下限 40 %**:ツインで 2500 → 1000 rpm の減速時に 415 rpm まで落ちて失速しかけたため。目標は 750–3200 rpm(40 % での 712 rpm が回り続けられる下限)。
- ゲインはツイン(`motor_twin.py` の `Firmware.control`)で決めてからファームに入れ、実機で同じステップ(1500 → 2500 → 1000 → 2000 rpm)を確認しました(`data/rpm_ctl_run1.*`)。

| 目標 | 実機(フィルタ値) | ツイン | 実機 duty | ツイン duty |
|---|---|---|---|---|
| 1500 rpm | 1490 | 1493 | 149.8 | 146.3 |
| 2500 rpm | 2492 | 2492 | 232.8 | 244.7 |
| 1000 rpm | 989 | 999 | 118.0 | 119.4 |
| 2000 rpm | 1988 | 1983 | 187.7 | 188.3 |

- 両ページに `rpm:set` / `rpm:off` / `tel:on` と「回転数制御」プリセット、推力レーンを追加。**Web Serial で実機につなぐと**、送ったコマンドがツインと実機の両方に届き、実機の `TEL`(回転数、duty、実機回転数から計算した推力)がスコープに赤い点で重なります。Web Serial は claude.ai のページ内では使えないので、ローカルで開きます:

```bash
python3 -m http.server 8765 --directory twin
```

## 空力モデル:翼素運動量理論(`bemt.py`、現行パラメータ)

プロペラの負荷を `c·ω²`・`kT·ω²` の 2 定数から、**実測形状の BEMT** に置き換えました。

**形状(同定しない)**
- 弦長:平置き写真の輪郭(`CHORD` 表)。R = 32 mm、ハブ/R = 0.345、3 枚。
- ピッチ:**18°、ねじれなし**。周回動画 `IMG_5778.MOV`(机に置いたプロペラ + 10 円玉、30 s)の 230 フレームから Object Capture でメッシュを作りました。点群を 120° 回すと自分に重なる軸を回転軸とし、半径ごとの円筒で切った断面の弦の角度を測っています。3 枚の平均は r/R 0.55 / 0.60 / 0.65 で 17.9 / 17.6 / 18.0° です。羽根ごとの ±4° のずれは、軸の推定に残った傾きによるもので、3 枚の平均では打ち消されます。スキャンから測った弦長は `CHORD` 表と約 5 % で一致し、平面形の独立な確認にもなりました。反りは断面に見えますが、メッシュのノイズで比率は決まりません。データは `data/prop_pitch_IMG_5778.json` と `data/prop_sections_IMG_5778.png`。

**モデル**:各円環で、静止推力の運動量の式(Prandtl の翼端・ハブ損失入り)と翼素の力を釣り合わせます。翼型は Re ≈ 1e4 の薄板として、`cl = kL·2π·α`、`cd = kD·(2.656/√Re + 2 sin²α)`。トルクは誘導分(揚力の傾き)と形状抵抗分に分け、ω の表(0–500 rad/s、25 刻み)にしています:`T = kT(ω)·ω²`、`Q = (kQi(ω) + kD·kQp(ω))·ω²`、後流 = `kV(ω)·ω`。

**較正(2 パラメータ)**
- `kL = 0.81`:天秤の推力 5 点(`thrust_IMG_5769.json` + `adc:emf` の回転数)に合わせた。χ² = 1.7。反り・低 Re・弦長が半径に近いほど幅広い羽根どうしの干渉・真下の紙コップをまとめた「揚力の効き」です。
- `kD = 3.6`:`fit_joint.py --fix-K 6.06e-3 --free-V0 --free-b --bemt` で、従来の c の代わりに同定。形状抵抗は薄板モデルの約 3.6 倍です。全速では誘導トルク 0.11 mN·m に対して形状抵抗トルク 0.15 mN·m で、**静止推力効率 FM ≈ 0.3** になります。

| rpm | 推力 gf(実測) | 空力トルク mN·m | 後流 m/s | ½T·v mW | FM |
|---|---|---|---|---|---|
| 712 | 0.09(0.10) | 0.019 | 0.83 | 0.4 | 0.21 |
| 1628 | 0.47(0.48) | 0.081 | 1.92 | 4.6 | 0.26 |
| 2216 | 0.88(0.84) | 0.139 | 2.62 | 11.7 | 0.28 |
| 3155(ツイン全速) | 1.79(1.90 @ 3164) | 0.262 | 3.74 | 32.9 | 0.31 |

`fit_joint.py` の定常回転数(観測 A・E)を解く式に、**粘性摩擦 b が入っていなかった**のを直しました。直すと b は 3.6e-7 から 7.7e-7 になります。新しい同定値は R = 8.4 Ω、L = 3.5 mH、V0 = 1.75 V、回転子 J = 2.67e-7、Tc = 0.25 mN·m、b = 7.7e-7、V_bk = 2.6 V です。13 観測はすべて ±1.8σ 以内で、最大は全速 A の +1.8σ(52.6 vs 50.8 Hz。撮影ごとの温まりで 51.3–48.6 Hz とばらつく量)。

両ページは BEMT を JS に移植して、ページ内で同じ表を作ります(Python の表との差 < 5e-4 = 書き出し時の 4 桁丸め)。パラメータ欄でピッチ・kL・kD を動かすと、表を作り直します。全速(3155 rpm、1.79 gf、3.74 m/s、空力 86.6 mW)、100→20 % の停止(1.004 / 1.005 s)、プロペラなし全速(3673 rpm)は Python と一致を確認済みです。

```bash
python3 twin/bemt.py                       # kL を推力に合わせ、回転数ごとの推力・トルク・後流を表示
python3 twin/fit_joint.py --fix-K 6.06e-3 --free-V0 --free-b --bemt --write
python3 twin/bemt.py --kD 3.609 --write    # 同定した kD で表を作り直す
```

## 逆転の予測(実測前、`data/reverse_prediction.json`)

逆転(`dcm:speed -N`)では、空気を**下向きにコップの上面へ**吹き付けます。コップ上面は Ø49.6 mm、プロペラ面の 14 mm 下にあり、r/R < 0.78 の範囲を覆っています。`bemt.py` は方向ごとに表を持ち、逆転側には次の 2 つを入れています。

- **部分的な地面効果**:Cheeseman–Bennett の補正 `1 − (R/4z)²` に、コップの上を通る流量の割合をかけたもの。全速では、同じ推力に必要な誘導速度が 0.82 倍になります。z/R = 0.44 は式の適用範囲(z/R > 0.5)のやや外です。
- **天秤の読み**:コップは装置の一部なので、コップの上を通る分の推力の 80 % が装置の中で打ち消し合います(η = 0.8、事前値)。天秤には残りだけが表れます。

**反り**:スキャンの断面は上面(ドーム側)が膨らんで見えます。ただ、これを「正転で逆向きに効く反り」と読むと、f/c ≥ 0.03 では kL を 3 にしても正転の推力 1.9 gf に届きません。正転の推力からは、反りは f/c ≳ −0.005 に制限されます(kL ≤ 1 の場合)。向きは決められないので、ツインは f/c = 0 とし、+0〜+0.05 を不確かさの幅として示します。2D 版のパラメータ欄の「反り f/c」でこの幅を試せます。

| 全速 100 % | 正転 | 逆転(f/c = 0) | 逆転の幅(f/c 0〜+0.05) |
|---|---|---|---|
| 回転数 | 3155 rpm | **3091 rpm(−2 %)** | 2932〜3091 |
| プロペラの推力 | +1.79 gf(上へ吹く) | −2.17 gf(下へ吹く) | −0.67〜−2.17 |
| **天秤の読み** | **+1.79 g** | **−1.36 g** | **−0.42〜−1.36** |
| 電流 | 0.127 A | 0.131 A | — |
| 惰性停止(全速から) | 0.742 s | 0.720 s | — |

部分 duty(標準):80 % は +2228 / −2178 rpm、天秤 +0.89 / −0.67 g。60 % は +1625 / −1589 rpm、天秤 +0.47 / −0.36 g。

**見分けるには**:反りの向きに最も敏感なのは**天秤の読み**です(−0.4 g なら反りは正転に有利、−1.4 g なら反りなし、それ以下なら正転に不利)。回転数の差(2〜7 %)は温まりによるドリフト(5 %)と同程度なので、正転と逆転を数秒おきに交互に測ります。

**逆転を測るときの注意**:電流が切れた瞬間に端子 A が VCC2 + Vf ≈ 5.9 V まで跳ね上がり、TOUT が約 0.98 V と上限 1 V ぎりぎりになります。**逆転の前に 10 kΩ を端子 A から外して**ください。外すと `adc:emf`・`rpm:set`・`tel:on` は使えないので、回転数は音声のブラシ音(全速)と動画で測ります。

### 逆転の実測(`IMG_5779.MOV`、`data/reverse_IMG_5779.json`)と予測の答え合わせ

`tools/run_sequence.py --preset reverse` で、100 % の正転と逆転を 3 往復、80・60 % を 1 往復しました。TOUT のジャンパーは抜いてあります。動画 = ホスト + 2.84 s で、ブラシ雑音の包絡線をコマンド時刻に合わせて決めました(Tink 音はモーター音に埋もれた)。

| | 実測 | 予測(f/c 0〜+0.05) |
|---|---|---|
| 天秤 正転 100 % | +1.63 / +1.60 / +1.55 g(平均 +1.59) | +1.70 gf @ 3070 rpm |
| 天秤 逆転 100 % | −0.15 / −0.10 / −0.17 g(平均 −0.14) | −1.36〜−0.42 |
| 全速回転数 正転 | 51.56 → 51.10 → 50.88 Hz(温まり −0.010 Hz/s) | |
| 全速回転数 逆転 − 正転 | **+0.29 ± 0.13 Hz(+0.57 %)**(ドリフトを直線で除去) | −2〜−7 % |
| 天秤 80 % / 60 %(正転, 逆転) | +0.67, −0.05 / +0.40, 0.0 g | |

- **天秤**:逆転の後流は、コップ上面だけでなく、装置ごと載っている天秤の皿にも当たります。運動量の約 93 % が天秤に戻るので、**天秤では逆転の推力を測れません**。モデルは「天秤 = −(1 − η)·T、η = 0.93」に直しました(以前はコップ上面の分だけ差し引いていた)。正転は空気が上の何もない空間へ出ていくので、この問題はありません。今回の正転 +1.59 g は IMG_5769 の 1.9 gf より低めです(n² で換算すると 1.79)。基準が 34.1 → 30.6 g と変わっており、皿の上の配置が違うためと考えられます。
- **回転数**:逆転のほうが 0.6 % 速く、「地面効果で負荷が増えて 2〜7 % 遅くなる」という予測は外れました。ただし、モーター自体が方向によって速さが違う可能性(ブラシの位置)を分けていません。**プロペラを外して正転と逆転を交互に測れば**、モーター単体の差がわかり、空力の差だけを取り出せます。
- 80・60 % の回転数は、音声のブラシ音が 1 kHz PWM の線に引きずられて読めませんでした。

### モーター単体の方向差(`IMG_5780.MOV`、プロペラなし、`data/bare_reverse_IMG_5780.json`)と空力の方向差

プロペラを外し、100 % の正転と逆転を 4 往復しました(`tools/run_sequence.py --preset bare`、動画 = ホスト + 2.10 s)。音声のブラシ音から:

- 正転 71.70 → 72.60 Hz、逆転 70.49 → 70.93 Hz。温まると速くなる(+0.0126 Hz/s)。
- **逆転 − 正転 = −1.57 ± 0.08 Hz(−2.19 %)**。プロペラがなくても、モーター側だけで逆転は 2.2 % 遅くなります。ツインには、逆転で L293D の降下が 0.061 V 増える(逆転では反対側の半分を使う)として入れました(`params.json` の `dV0_rev`、JS は `dV0r`)。逆転で摩擦が増える仮説でも、プロペラ付きへの効き方は同じです(−2.0 %)。
- **プロペラありでは逆転が +0.57 % 速かった**ので、モーター分(−2.0 %)を除くと、**空力の負荷は逆転のほうが軽い**ことになります。空力トルクは −19 %、形状抵抗の倍率は **kD_r = 1.67**(正転 3.61)。正転の kD には、真下のコップが吸い込みをふさぐ損失など、正転に特有の損失が含まれていると考えられます。BEMT の「コップへの地面効果で逆転は +12 % 重くなる」という予測は外れました。
- ツインは今、プロペラあり 正転 52.59 / 逆転 52.97 Hz(+0.72 %、実測 +0.57 ± 0.25 %)、プロペラなし 61.22 / 59.87 Hz(−2.20 %)を再現します。Python と両ページで一致を確認済みです。逆転の推力(−2.34 gf)は、天秤では確かめられません。

**ADC での確認(TOUT を戻して、プロペラなし・旗なしの正転、`tools/bare_speed_adc.py`)**:通電中の整流子リップルは 220.8 Hz で、÷ 3 = **73.6 Hz**。`adc:emf` の 6 回平均も約 74 Hz で、音声の 71.7〜72.6 Hz を裏付けました(半分の 35.85 Hz ではない)。IMG_5759 の 61.4 Hz は軸にテープの旗が付いた状態の値で、**旗の空気抵抗だけで約 12 Hz 遅くなっていた**ことになります。同時同定の粘性摩擦 b = 7.7e-7 は、大部分が旗の抵抗です。旗の抵抗を別の項にして、同定し直しました(次の節)。

### 同時同定のやり直し(旗の抵抗を分離、`fit_joint.py --fix-K 6.06e-3 --free-V0 --free-b --bemt --flag`、現行パラメータ)

IMG_5759 のプロペラなしの観測(E・F・G・H)は、旗の空気抵抗 `c_flag·ω|ω|` を別の項として扱いました。さらに 3 つの観測を加えています:旗なしの全速 E0 = 73.0 ± 0.8 Hz、プロペラなしの方向差 Rb = −2.19 ± 0.11 %、プロペラありの方向差 Rp = +0.57 ± 0.25 %。BEMT の表と 2 巡させて収束させました。

|---|---|---|
| b(モーターの粘性摩擦) | 7.7e-7 | **2.9e-7** |
| c_flag(旗の抵抗、モーターの外) | — | **1.76e-9** |
| kD / kD_r(形状抵抗の倍率、正転 / 逆転) | 3.61 / 1.67 | **7.92 / 5.57** |

16 観測すべてが ±1.8σ 以内です(最大は全速 A の +1.8σ。温まりによるばらつきの範囲)。E0・Rb・Rp は 0.1σ 以内で合っています。旗の抵抗が b から抜けたので、そのトルクがプロペラ側に移り、空力トルクは全速で 0.45 mN·m(誘導分 0.12 + 形状抵抗分 0.33)になりました。**FM ≈ 0.18** で、最初に推力から見積もった 0.16 に近い値です。逆転の空力トルクは正転より約 30 % 小さくなります(kD_r / kD = 0.70)。
